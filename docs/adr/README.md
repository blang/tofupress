# Architecture Decision Records

Decisions that are hard to reverse, surprising without context, and the result of a real trade-off. Each ADR records *that* a decision was made and *why* — the code follows.

## Format

1–3 sentences of context, the decision, and the why. Optional sections (`Status`, `Considered Options`, `Consequences`) included only when they add value. Numbered sequentially; `0001-slug.md`. See [`CONTEXT.md`](../../CONTEXT.md) for the glossary the ADRs share.
