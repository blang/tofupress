# Adversarial correctness and architecture review

Date: 2026-07-29
Branch reviewed: `feature/improvement`
Scope: CLI acquisition and command seams, source classification, resolver, strip planner, identity/staging, archive writers, metadata, documentation, and QA/acceptance contracts.

## Method

The review followed user-visible execution paths (`module`, `tree`, and `resolve`) before evaluating exported library seams. Findings were ranked by silent data corruption, boundary/security impact, artifact validity, and operational blast radius. A finding was not ranked merely because code was large or aesthetically imperfect.

“Fixed” below means the change is covered by a focused regression test and the complete project gates. “Mitigated” means the immediate failure mode is fixed but the deeper architectural seam remains.

## Ten largest concrete flaws

| Rank | Finding | Adversarial assessment | Status and evidence |
|---:|---|---|---|
| 1 | A pivoted `module package//entry` could silently corrupt geometry: escaping filesystem reads became invalid, and a local module targeting the package root was copied over the selected entry at archive root. | One could argue that callers should choose `tree`, but the CLI produced a successful artifact whose `path.module` meaning or root module bytes no longer represented the selected entry. That is artifact corruption, not misuse. | **Fixed conservatively.** Static escaping reads, unprovable dynamic entry reads, and package-root module collisions are refused with `tofupress tree` as the remedy. Tests: `TestRunModuleRefusesFilesystemReadThatEscapesPivotedEntry`, `TestBundler_RefusesPivotWhenLocalModuleTargetsPackageRoot`, `TestAcceptance_Git_SubdirHostShorthandRefusesUnpreservablePivot`, and `TestIntegrationTreeArchivePreservesLegalSiblingReads`. |
| 2 | Archive writers created/truncated the destination directly, ignored cancellation during walks/copies, and deferred every input close until the entire walk ended. | Small fixtures hide all three defects. Large trees can exhaust descriptors; cancellation can still publish an artifact; a late error destroys a previously good output. | **Fixed.** All formats share one staging transaction, write to a sibling temporary file, close/sync it, re-check context, then rename. Walks and file copies honor context and close each input immediately. Unit: `TestBundler_CanceledWritePreservesExistingArtifact`; existing ZIP/tar parity tests cover successful replacement. |
| 3 | Parallel package downloads shared go-getter singleton instances even though `Client.Get` mutates every getter via `SetClient`; GitGetter also mutates per-request state. | Parallel fetching looked valid because destinations and result slots were independent. The race detector showed that request contexts and getter settings could cross-contaminate, so this was not merely a noisy dependency diagnostic. | **Fixed.** Every default fetch receives fresh getter instances; the HTTP/HTTPS alias is shared only within one client, and arbitrary injected getter instances are serialized because they cannot be cloned safely. Tests: `TestFetcher_DefaultGettersAreIsolatedPerFetch` and `TestFetcher_ConcurrentFetchesUseIsolatedGoGetterClients`; the affected resolver tests pass under `-race`. |
| 4 | Symlinks followed during acquisition/resolution/staging could escape the package or recurse cyclically, while package hashing skipped links entirely and could deduplicate packages whose dereferenced artifact content differed. | Dereferencing is useful for portable archives, so rejecting every symlink would be an overreaction. Canonical targets must stay inside the explicit package, active-directory cycles must terminate at every seam, and content identity must hash exactly the dereferenced bytes staging exposes. | **Fixed without dropping internal symlink support.** Unit: `TestCopyDirRejectsSymlinkOutsideSource`, `TestCopyDirRejectsSymlinkDirectoryCycle`, `TestCopyDirResolvesSymlinks`, `TestResolver_RejectsTerraformFileSymlinkOutsidePackage`, `TestResolver_RejectsLocalModuleSymlinkOutsidePackage`, `TestResolver_DetectsCycleThroughSymlinkAlias`, `TestHashModule_DifferentSymlinkTargetsDifferentHash`, `TestSnapshotDirectoryRejectsSymlinkOutsidePackage`, `TestStageBundle_RejectsSymlinkOutsidePackage`, and `TestStageBundle_RejectsSymlinkDirectoryCycle`. |
| 5 | An ordinary local path was implicitly expanded to the nearest Git root, copying unrelated repository content and making unrelated links/files affect the press. | Repository expansion is convenient for `../` references, but it is invisible content sniffing and contradicts the package-boundary hint that tells users to use `//`. It also turns a narrow input into a broad trust boundary. | **Fixed.** Local package boundaries are exact; parent/sibling inclusion requires `package//entry`. Unit: `TestLocalSourceDoesNotExpandToContainingGitRepository`. ADR-0002 and README now state the explicit rule. |
| 6 | Path components were trusted at multiple seams: root `//subdir` could escape its fetched package, downloaded archive names lacked one host-independent path contract, `--vendor-dir` accepted traversal/reserved paths, source-derived package namespaces could become `../`, hand-built package IDs or module keys could escape staging, and Linux filenames containing backslashes could become traversing entries for Windows extractors. | Resolver-generated hashes and normal subdirectories hid most cases, but root sources and Git/registry provenance are untrusted and Bundler is exported. Every value used as a filesystem/archive path needs a portable containment invariant, not just the CLI flag. | **Fixed and validated before side effects.** Root subdirectories are checked canonically; extraction and output archive names use host-independent slash-path validation; vendor names are one safe component; source namespaces fail back to content IDs; all dynamic staging joins enforce containment; archive names satisfy a cross-platform slash-path contract. Tests: `TestResolveSourceRejectsSubdirectoryTraversal`, `TestArchiveExtractionPath`, `TestValidateVendorDir`, `TestResolver_RejectsUnsafeVendorDirBeforeCreatingIt`, `TestRunModuleRejectsUnsafeVendorDirBeforeFetchingSource`, `TestResolver_RejectsInvalidModuleLabel`, `TestNamespacedPackageID`, `TestJoinPathWithin`, `TestPortableArchivePath`, `TestBundler_RejectsCrossPlatformTraversingArchiveName`, `TestStageBundle_RejectsTraversingPackageIdentity`, and `TestStageBundle_RejectsTraversingModuleKey`. |
| 7 | Full staging silently skipped every user directory named `sourcetree`, and embedded metadata could overwrite a user `.tofupress/meta.json`. | Both names originated internally, but name-based sniffing makes ordinary user content disappear. Silent replacement is unacceptable even if the path is documented as internal. | **Fixed.** Only actual generated/VCS directories are skipped; a reserved metadata collision is explicit. Unit: `TestStageBundle_PreservesLegacyNamedUserDirectory` and `TestStageBundle_RejectsMetadataPathCollision`. |
| 8 | Resolver limits were off by one for remote modules, checked after registry/network work, and bypassed by `tree` entry seeds. | Defaults are unlimited, but once configured these fields are resource/safety controls. A limit that performs the expensive work first or rejects the exact bound is not a limit. | **Fixed.** Nodes are checked before admission and before remote work; the synthetic tree container is excluded intentionally. Unit: `TestResolver_MaxModulesAllowsExactRemoteLimit`, `TestResolver_MaxModulesStopsBeforeRemoteFetch`, and `TestResolveTree_MaxModulesIncludesEntrySeeds`. |
| 9 | Source parsing had two implementations; query-before-subdir input was split incorrectly; host shorthand could emit the bad ordering; OCI subdirectories were not separated; and enum zero mislabeled unknown input as local. | Query-before-subdir is noncanonical and ambiguous in isolation, but TofuPress itself could emit it. Unknown-as-local also changed control flow rather than merely changing a label. | **Fixed.** Command code delegates to one core parser, shorthand emits canonical ordering, compatibility input is accepted, OCI uses package/subdir splitting, and `SourceUnknown` is an explicit zero value rejected by the resolver. Tests: `TestSplitPackageSubdir`, `TestClassifySource_HostShorthand`, `TestClassifySource_OCI`, and `TestResolver_ResolveInvalidSource`. |
| 10 | Metadata, inspection output, nested fetch errors, and lenient OCI warnings could expose URL credentials, signed-query values, or ephemeral absolute paths; the directory reader also masked non-`ENOENT` errors at the relocated metadata path. | Raw provenance is useful, but passwords/tokens are never legitimate provenance and temporary paths are neither stable nor useful. Redacting only an outer wrapper is ineffective when a nested downloader repeats the raw URL; falling back after a permission/type/I/O error hides corruption. | **Fixed.** One fail-closed projection preserves host/repository/ref/subdir while sanitizing metadata, CLI progress, nested getter errors, and injected OCI warnings; plans are copied rather than mutated and only absence triggers legacy metadata fallback. Tests: `TestRedactSourceAddress`, `TestRedactSourceAddressEscapesTerminalControls`, `TestRedactSourceSecretsInTextEscapesNestedTerminalControls`, `TestModuleBlock_StringRedactsSourceCredentials`, `TestModuleSource_StringRedactsCredentials`, `TestFetcher_FetchErrorRedactsSourceSecrets`, `TestResolveSourceWithFetcherRedactsNestedGetterErrors`, `TestEnforceArtifactType`, `TestBuildArtifactMetadataRedactsCredentialsAndEphemeralPaths`, and `TestReadMetadataFromDirDoesNotMaskRelocatedMetadataErrors`. |

### Additional high-value fixes landed

- Duplicate module labels are tracked across all `.tf`/`.tofu` files in one module instead of only within each file (`TestResolver_RejectsDuplicateModuleNamesAcrossFiles`).
- Local children already owned by downloaded packages are staged only with that package, rather than duplicated at a string-derived module-key path (`TestStageBundle_DoesNotDuplicateModulesOwnedByDownloadedPackage`).
- Pivot source rewrites now modify only the disposable staged entry, not the caller's resolved workspace (`TestBundler_PivotRewritesOnlyStagedEntry`).
- Local archive acquisition extracts into a sibling transaction and replaces the downloaded archive, rather than accidentally embedding both the archive and its contents (`TestExtractArchiveIfNeededReplacesArchiveInsteadOfBundlingIt`).
- Strip statistics now assign each physical file to the narrowest owning package, reset before recomputation, and do not count overlapping package roots twice (`TestStripPlanStatsCountOverlappingPackageFilesOnce`).
- Boundary/path ownership checks distinguish actual `..` traversal from legal in-package names such as `..generated`, preventing silent strip/staging mistakes (`TestPlanStrippingKeepsResolvedModuleWhoseNameStartsWithTwoDots`, `TestRelPathNoLeak`).
- `resolve` now actually registers strict OCI validation with the same default as press commands (`TestResolveCommandRegistersStrictOCIEnabledByDefault`).
- Press format/OCI/strip/vendor validation runs before source acquisition (`TestRunModuleValidatesFormatBeforeSourceAcquisition`).
- Progress and lenient OCI warnings use injected, concurrency-safe writers rather than bypassing Cobra on global `os.Stderr` (`TestNewPressResolverUsesCommandErrorWriter`, `TestFetcher_WarningWriterPropagatesToFreshOCIGetter`, and `TestResolver_SerializesProgressCallbacks`).
- Root-subject acquisition and nested dependency resolution now share one owned fetcher, so strict-OCI policy, getter isolation, warning routing, and nested-error redaction cannot diverge (`TestResolveSourceWithFetcherRedactsNestedGetterErrors`).
- The shell QA suite builds a fresh isolated binary and exercises `module` and `tree`; all 54 checks pass. README and tagged acceptance tests no longer teach or assert the removed `bundle` command.

## Ten largest architectural mistakes

These are ranked separately from defects. Several immediate manifestations were fixed, but the deferred items should guide the next design cycle.

| Rank | Architectural mistake | Why the counterargument does not remove the risk | Status / recommended direction |
|---:|---|---|---|
| 1 | `ResolvedTree` is simultaneously a dependency graph, provenance record, and mutable filesystem workspace. Identity application rewrites HCL, moves/deletes package directories, and rewires node paths. | “The CLI always works in a temp directory” protects the original user checkout, but not exported library callers, rollback, retry, or reasoning about whether a graph is still valid. | **Deferred.** Introduce immutable `ResolvedGraph`/package identities and a separate disposable `Workspace` or `StagingPlan`; make transformations return a new plan instead of mutating graph provenance. |
| 2 | The roughly 1,000-line resolver owns scanning, validation, registry protocol, fetch batching, deduplication, graph construction, boundary checks, and source rewriting in one BFS body. | BFS is inherently stateful, but that does not require protocol I/O, graph admission, and file mutation to share one control structure. The prior late-limit bug is evidence that policy is hard to place correctly. | **Partly mitigated** by pre-admission validation. Split into graph frontier/admission, package acquisition, and rewrite/materialization modules with narrow result types. |
| 3 | Source acquisition is split between `pkg/cmd` (`resolveSource`, local copying, archive extraction) and core (`Fetcher`, OCI, resolver), so the complete press operation is not a coherent library service. | Keeping Cobra thin is not enough when a library caller cannot obtain the same source/boundary behavior as the CLI without reimplementing command internals. It also caused strict-OCI divergence. | **Partly mitigated:** root acquisition and dependency resolution now share one configured fetcher. Still create a core `PressService`/`SourceAcquirer` that owns Acquire → Resolve → Plan → Stage → Write; leave Cobra as argument/output adaptation. |
| 4 | Press shape is inferred from path relationships (`PackageRoot != InstallDir`) and resolver seeding uses a boolean, rather than carrying an explicit domain type for `module` versus `tree`. | The two adapters are small, but path geometry is not a reliable semantic discriminator. The pivoted-filesystem corruption escaped precisely because shape was implicit downstream. | **Mitigated** by an explicit pivot-safety gate. Introduce `PressKind`/`PressSubject` with entry, package boundary, and archive-shape invariants validated once. |
| 5 | Resolver/Bundler configuration is exposed as mutable exported fields, while Cobra commands and some build/logger state are package globals. | Alpha compatibility explains the fields but does not make concurrent reuse, configuration freeze, or test isolation safe. Options layered on top do not prevent post-construction mutation. | **Partly mitigated:** `Bundle` no longer mutates `Bundler.VendorDir`, and `WithVendorDir` is honored without mutating the tree (`TestBundler_WithVendorDirIsHonoredWithoutMutatingTree`). Still move to private immutable config, construct commands per invocation, and inject writers/loggers/build info. |
| 6 | Archive formats had separate staging paths and duplicated tar walkers with no transactional output abstraction. | ZIP and tar necessarily differ at encoding, but staging, cancellation, close discipline, and commit semantics do not. Duplication already caused all formats to share the same defects. | **Fixed/deepened.** One staging transaction, one tar walk with compressor injection, one atomic commit seam; only codec-specific entry writing remains separate. |
| 7 | Resolver concurrency treated go-getter’s globally exposed getter map as a registry of stateless services, although each getter stores its current client and some store request state. | Copying the map looked like isolation, but it copied interface pointers. Concurrency boundaries must be based on ownership of mutable values, not container ownership. | **Fixed/deepened.** Fetches allocate a private default getter graph per request; injected opaque getters cross an explicit serialized boundary. Keep the race gate to enforce this ownership rule. |
| 8 | Source addresses and progress events are stringly typed; source parsing was duplicated and `SourceType(0)` accidentally meant local. | Terraform source syntax starts as a string, but it should become one validated parsed value at the boundary. Likewise arbitrary event strings leave callback contracts implicit. | **Partly fixed.** Source zero/parsing are corrected and centralized. A parsed `SourceAddress` and typed progress event enum remain deferred. |
| 9 | Strip ownership is inferred repeatedly from overlapping path-prefix plans rather than represented explicitly. | Longest-prefix lookup can work, but every consumer must remember the same narrowest-owner rule. The byte-accounting defect showed that one independent walk did not. | **Partly fixed.** Statistics now use narrowest ownership. Build an explicit path/package ownership index once and make inclusion/staging/stats consume it. |
| 10 | Context was present in signatures but not a consistently enforced lifecycle contract, especially in archive walks and source-tree copying. | Passing `context.Context` creates an expectation of prompt cancellation. Ignoring it is worse than omitting it because callers believe they have control. | **Partly fixed.** Archive walks/copies and atomic commit honor context; thread context through staging and local recursive copy next. |

## Deliberately conservative choices and residual limits

- Pivot safety rejects unprovable dynamic entry filesystem paths. This can reject a path that happens to stay inside at runtime, but accepting it would claim hermetic validity without evidence. `tree` is a behavior-preserving escape hatch.
- Query-before-subdirectory parsing remains a compatibility heuristic because that spelling is intrinsically ambiguous when query values contain raw URLs. TofuPress now emits canonical subdir-before-query addresses.
- Credential redaction recognizes common auth/signature key families; an arbitrarily named secret query parameter cannot be inferred perfectly. Callers should still avoid credentials in source strings and prefer external credential providers.
- Internal filesystem symlinks remain supported and are dereferenced; external targets and dangling/cyclic links fail loudly instead of being silently skipped. Local archive symlink records fail closed pending a safe two-phase extractor.
- Archive extraction enforces path and entry-type safety, but expansion byte/file-count quotas are not yet uniform because go-getter owns remote archive expansion. Run acquisition in a storage-bounded workspace until the proposed core `SourceAcquirer` owns this policy.
